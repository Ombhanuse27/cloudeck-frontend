Switch Widget Configuration

Example Screenshot of Switch Widget Configuration

Title: Enter the name of your widget. This will be displayed above the switch.
Datastream: Select which datastream the switch should control. This defines where ON/OFF values will be sent.
On Value & Off Value: - ON Value → 1 - OFF Value → 0 These values are sent to your device when the switch toggles.
Show On/Off Labels: Tick this if you want visible labels near the switch.
On Label & Off Label: Enter custom text for ON and OFF states. Example: ON → START, OFF → STOP
Label Position: Choose where the label appears → Left, Right, Top, Bottom.
Hide Widget Name: Check this if you want to hide the widget title for clean UI.
